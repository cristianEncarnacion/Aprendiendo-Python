# Aprendiendo IA y Machine Learning desde Cero 🤖🧠

Este repositorio documenta mi proceso de aprendizaje en Inteligencia Artificial, desarrollando modelos paso a paso utilizando Python. El objetivo es avanzar desde la lógica matemática de algoritmos clásicos hasta arquitecturas de Deep Learning.

## 🗂️ Estructura del Proyecto

### Módulo 1: Machine Learning Clásico 📊
En este primer módulo construí mi primer modelo de clasificación desde cero.
* **Conceptos dominados:** * Características (*Features*) y Etiquetas (*Labels*).
  * Traducción de datos categóricos a numéricos (Codificación).
  * Separación de datos (Entrenamiento vs. Prueba) y el problema del Sobreajuste (*Overfitting*).
* **Herramientas:** Python y `scikit-learn`.
* **Archivos:**
  * `modulo_1_ml_clasico/1_knn_frutas.py`: Modelo predictivo basado en el algoritmo **K-Vecinos Más Cercanos (KNN)**. Clasifica frutas (como manzanas, naranjas o tomates misteriosos) evaluando matrices de datos con su color y forma.
